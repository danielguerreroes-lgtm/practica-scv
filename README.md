# Práctica de Sistemas de Control de Versiones

Repositorio de ejemplo para el ejercicio de Git de la práctica.

## Recorrido realizado

- `.gitignore` ignora los Markdown salvo `README.md` y `LICENSE.md`.
- `carpeta-vacia/` se conserva mediante `.gitkeep`, porque Git no versiona directorios vacíos.
- Se crearon ramas de funcionalidad y de integración; una fusión requirió resolver un conflicto.
- La rama `feature` se rebasó sobre `main`, recibió otro cambio y se fusionó.

Consulta `ENTREGA.txt` para publicar este repositorio en GitHub.
